# Pimlico Fresh Website

A modern, bold website for Pimlico Fresh cafe in London.

## Features

- **Bold Block Colors**: Vibrant color scheme with orange, blue, and yellow
- **Responsive Design**: Works beautifully on all devices
- **Smooth Navigation**: Easy-to-use navigation with smooth scrolling
- **Modern Layout**: Clean, contemporary design

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling with block colors
- `script.js` - Smooth scrolling and interactive features

## Opening the Website

Simply open `index.html` in your web browser, or serve it using a local web server.

## Customization

The color scheme can be easily modified in `styles.css` by changing the CSS variables in the `:root` selector:

```css
:root {
    --primary: #FF6B35;    /* Orange */
    --secondary: #004E89;  /* Blue */
    --accent: #FFD23F;     /* Yellow */
    --dark: #1A1A1A;       /* Dark */
    --light: #F5F5F5;      /* Light */
    --white: #FFFFFF;      /* White */
}
```
